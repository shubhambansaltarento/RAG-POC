# AI SDLC Copilot

An AI-powered Software Development Lifecycle Assistant that helps engineering teams with:

- Knowledge Search
- Requirement Analysis
- Test Case Generation
- Release Notes
- Impact Analysis
- AI Chat over Enterprise Documents

## Tech Stack

Frontend:
- React
- TypeScript

Backend:
- Node.js
- Express

Database:
- PostgreSQL
- Prisma

AI:
- OpenAI
- LangChain
- ChromaDB
